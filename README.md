# design-stuff

Scratchpad for UI/motion experiments. Each component in `src/components` is a standalone interaction study; `src/app/page.tsx` mounts whichever one is being worked on.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · lucide-react

## Getting started

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Scripts

- `pnpm dev` — dev server
- `pnpm build` — production build
- `pnpm start` — serve build
- `pnpm lint` — ESLint
